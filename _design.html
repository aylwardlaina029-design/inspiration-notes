「灵感记录」视觉设计方案

清新自然 · 绿色治愈系 redesign —— 功能结构不变，仅重构视觉层

📐 适配：移动端优先（PWA） 🎨 主色：自然绿 #4E9A6C 📦 范围：5 页面 · 3 模块 · 全套组件
设计概览色彩系统图标系统 页面应用组件规范移动端适配

00设计概览

先想清楚"要什么样的感觉"，再谈色值。现状是冷蓝工具风，与"记录生活"的定位错位；新方案的关键词是：

清新自然治愈轻松干净
  • 纸感优先：暖米白页面底（#F7F5EF）+ 纯白卡片，像摊开在桌面上的手账，而不是一块屏幕。
  • 绿为骨架，彩为点缀：主色自然绿承担所有"操作与选中"，三个模块各配一个自然系辅助色，只做小面积点缀（圆点、标签、图标），绝不抢主色的戏。
  • 圆角统一语言：全站圆角分四档（10 / 14 / 18 / 999），没有锐角；图标全部圆头线性，与圆角容器呼应。

02图标系统

风格一句话：圆头 1.8px 线性图标，24px 网格，转角全部圆弧——和全局圆角是同一种语言。现有的 emoji 心情保留（亲和力是优势），但图标全部换成统一线性风格。

2.1 造型建议总表

快速记录
羽毛笔 + 叶片结合，一笔落下的速度感
日历
圆角日历 + 内部一笔"微笑曲线"，弱化严肃感
灵感
灯泡升级为"灯泡里长出嫩芽"——创意发芽
菜单
三条圆头横线，长度 16/16/10 递减
到期提醒
水滴/叶子形轮廓，替代机械铃铛
导出 JSON
向上箭头 + 托盘，导出导入共用一套箭头语言

2.2 心情选择器（emoji 保留，容器重做）

五个 emoji 本身色彩丰富、辨识度高，是"治愈感"的重要来源，不建议换成线性图标（会变成"体检表"）。改造点在容器：

  • 未选中：浅绿卡底 #F2F7F3，emoji 原色；
  • 选中：绿底 #4E9A6C + 白边 emoji（可加 filter: saturate(1.1)）+ 轻微放大 1.04 + 柔和投影——形成"被阳光照到"的感觉。

4.1 按钮（四档语义）

主要按钮 次要按钮 描边按钮 危险按钮 幽灵按钮
类型填充 / 文字用法
主要#3F8759 / 白每屏最多一个：记下、写一条灵感、关闭
次要#DCEBE1 / #2F6543导入 JSON、分段未选项底
描边白底 / #6B7A6F 字，#E8E5DC 边低优先级并列操作

规格：高度 44px（小 34px），圆角 14px（小 11px），字号 14px（小 12.5px），字重 600；投影统一 0 4px 12px rgba(63,135,89,.28)（仅主要按钮与 FAB）。

4.2 标签 / Chips

任务提醒日程灵感归档

圆角 999（胶囊形），高 26px，字号 12px 字重 600；底色 = 对应色浅阶，文字 = 对应色加深变体。同一界面同屏 ≤3 种颜色标签。

4.3 输入框

默认态：浅绿底无边框
聚焦态：白底 + #9CC7AE 描边 + 3px 绿光环

圆角 13px，左右内边距 14px，占位文字用三级色。

4.4 空状态（三要素统一）

🍃
这里还空着
一句轻提示 + 一个行动建议

模板：一个自然系小装饰（叶/芽/蒲公英，emoji 或线性插画皆可）+ 二级色短句 + 三级色行动建议。全应用空状态保持同一构图，只换文案。

4.5 底部导航与 FAB

  • 底栏：白底、顶部 1px 分割线；未选中图标三级色，选中图标 Green 700 + 加粗小字；图标 22px。
  • FAB：52px 圆角方形（18px 圆角，squircle），Green 500 底 + 白色 24px 加号，投影 0 6px 16px rgba(78,154,108,.35)；点按时缩放 0.95 回弹，强化"高效"手感。
  • 菜单图标（右上角）：圆形浅绿底 + Green 600 线性菜单图标。

05移动端适配要点

  • 间距体系（8pt 网格）：卡片内边距 16–20px，卡片间距 12–14px，屏幕左右留白 16px——所有间距都是 4 的倍数。
  • 触控目标 ≥ 44×44px：心情 chip、日历格、分段控件全部达标；相邻可点元素间距 ≥ 8px 防误触。
  • 字号阶梯：12 / 13 / 15 / 17 / 20 / 24，基准 15px；标题字重 700，正文 400–500，保证阳光下可读。
  • 安全区：底部导航与 FAB 适配 env(safe-area-inset-bottom)；弹层顶部圆角不被刘海遮挡。
  • 深色模式（可选二期）：底 #1C2620、卡 #232F27、主色不变仅提亮到 Green 400，文字用 Green 900 的反阶。
  • 动效：统一 150–200ms ease-out；页面切换淡入上移 4px；选中态缩放 1.04——"轻"是治愈感的另一半。
